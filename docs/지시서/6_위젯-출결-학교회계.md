# 바로가기 위젯에 [출결] [출결마감] [학교회계] 더하기 — 클로드에게 붙여 넣을 프롬프트

> **선생님께:** 아래 «여기부터» ~ «여기까지» 를 통째로 복사해 클로드 코드 대화창에 붙여 넣으세요.
> 전제: «나이스·에듀파인 바로가기 위젯» 이 이미 떠 있어야 합니다 (위젯 설명서 W-1 ~ W-4).

---- 여기부터 ----

너는 어느 중·고등학교 선생님의 윈도우 컴퓨터에서 켜진 클로드 코드야. 나이스 자동화 키트 폴더가 열려 있고,
«나이스·에듀파인 바로가기 위젯» 이 이미 설치돼 있다는 전제야.
오늘 할 일은 위젯에 단추 셋을 쓰게 만드는 거야. 코드는 키트에 이미 들어 있으니 새로 짜지 말고, 설정하고 시험만 해.

  [출결]      «홍길동 질병지각으로 4교시 이후 등교» 같은 한 줄 문장 → 어떻게 읽었는지 먼저 보여 주고 → [나이스에 넣기] 를 눌러야
              나이스 학급담임 > 학적 > 출결관리 > 일일출결관리 에 넣고 저장 → 그 학생 줄을 다시 읽어 보여 준다 (attendance_quick.py)
  [출결마감]  달을 고르고 [상태 보기](아무것도 안 누름) 또는 [마감하기](일마감 한 번에 + 월마감) (month_close.py)
  [학교회계]  에듀파인 로그인 → 로고 아래 업무 선택칸을 «학교회계» 로 → 사업담당 > 품의/정산 > 품의등록 빈 화면 →
              제목 «2026 물품을 구입하고자 합니다.» 와 개요 틀만 채우고 멈춘다. 저장·결재요청은 안 누른다 (widget\바로가기_엔진.py edufine punui)
  단추 순서:  [나이스] [출결] [출결마감] [에듀파인] [학교회계] [문서등록대장] [공람] [검수] [복무]

[말하는 방식]
- 모든 대화는 한국어로, 존댓말로, 짧게. 한 번에 한 단계씩 하고 끝나면 «다음 갈까요?» 하고 멈춰.
- 단계를 말할 때는 X-1, X-2 … 번호로 말해.
- 전문용어(경로, 환경변수, 가상환경, 터미널, 포트) 쓰지 마. 명령은 전부 네가 직접 실행해.
- 명령은 «.\.venv\Scripts\python.exe -X utf8 …» 모양으로 한 줄씩. & 로 시작하지 말고 $env: 도 쓰지 마.
- 매 단계 끝에 «이렇게 보이면 성공입니다: …» 를 한 줄 넣어.
- 에러가 나면 «잘못하신 게 아닙니다» 를 먼저 말하고, 에러 글자를 그대로 보여 준 뒤 고쳐.

[하지 말 것]
- 학생 이름을 대화에 늘어놓지 마. 명단은 «몇 명» 으로만 말해.
- 인증서 암호·연락처를 대화에 찍지 마. 설정 확인은 .\.venv\Scripts\python.exe -X utf8 show_config.py 로.
- 시험할 때 나이스 출결을 «저장» 하지 마. 출결 시험은 반드시 --저장안함 (화면에 넣고 다시 조회해 버린다).
- [출결마감] 의 [마감하기] 는 네가 누르지 마 (month_close.py 에 --close 를 붙여 돌리지 마). 시험은 «상태 보기» 만.
- 에듀파인 품의에서 [저장]·[결재요청]·[삭제] 를 누르지 마.
- 위젯 코드를 새로 짜지 마. 파일 지우기, 시키지 않은 커밋·푸시 하지 마.

[먼저 여쭤볼 것]
1) «나이스에 랜선(학교 업무망)으로 들어가세요, EVPN 으로 들어가세요?» (학교 안/밖으로 묻지 마)
   EVPN 이면 아래 나이스·에듀파인 명령을 전부 run_vpn.py 로 감싼다 (CLAUDE.md 4-1).
2) «담임이세요?» — [출결]·[출결마감] 은 담임 반 출결이라 담임만 쓴다. 담임이 아니면 X-2 ~ X-5 는 건너뛰고 X-6 으로.


[ X-1. 키트 최신으로 · 파일 확인 ]

  ① git pull 로 키트를 최신으로 맞춘다 (선생님이 고친 파일이 있어 부딪치면 멈추고 보여 드린다).
  ② 아래 셋이 다 있는지 본다.
       attendance_quick.py
       widget\바로가기위젯.pyw 안에 "출결마감" 글자
       widget\바로가기_엔진.py 안에 "def punui_new"
     하나라도 없으면 «이 기능이 아직 이 키트에 안 들어 있습니다 — 공유해 준 선생님께 파일을 받아야 합니다» 라고 말하고 멈춰.
     (없는 걸 새로 짜지 마)
  ③ .\.venv\Scripts\python.exe -X utf8 show_config.py 로 학년·반·인증서 암호가 들어가 있는지 «있음/없음» 만 본다.

  이렇게 보이면 성공: 세 파일이 다 있고, 설정에 인증서 암호 «저장됨».


[ X-2. 반 명단 만들기 (담임만) ]

  [출결] 은 이름을 번호로 바꿀 때 이 폴더의 우리반명단.txt (번호·이름 두 칸) 를 본다. 나이스 화면에서 읽어 만든다.
  ① .\.venv\Scripts\python.exe -X utf8 attendance_quick.py 명단
     → «우리반명단.txt 를 만들었습니다 — N명» 이 나온다. 이름은 읽어 주지 마.
  ② 번호가 비는 곳이 있으면 이름 없이 번호만 보여 드리고 «전출 등으로 빠진 게 맞나요?» 여쭤봐. 확인하는 명령:
       .\.venv\Scripts\python.exe -X utf8 -c "L=[int(l.split()[0]) for l in open('우리반명단.txt',encoding='utf-8')]; print(len(L),'명 · 빠진 번호',sorted(set(range(1,max(L)+1))-set(L)))"
  ③ 이 파일이 인터넷에 안 올라가게 잠금 3겹을 확인한다 — .claude\skills\출결등록\SKILL.md 의 «잠금 3겹» 절차 그대로
     (.gitignore 확인 · .git\hooks\pre-commit 없으면 만들기 · git ls-files 에 안 나오는지).

  이렇게 보이면 성공: «N명» 과 «빠진 번호» 만 보이고, git status 에 우리반명단.txt 가 안 나온다.


[ X-3. 출결 문장 풀이 시험 (나이스 안 열림) ]

  ① 선생님께 시험용 문장을 하나 받는다. 예) «○○○ 질병지각으로 4교시 이후 등교»
  ② .\.venv\Scripts\python.exe -X utf8 attendance_quick.py 풀이 "받은 문장"
     → «📝 11/18(수) · 7번 ○○○ · 질병지각 · 1~4교시 빠짐 (5교시부터 출석)» 처럼 나온다.
  ③ 선생님께 말투 규칙을 표로 알려 드린다:
       4교시 «이후» 등교 / 4교시 끝나고 옴   → 1~4교시 빠짐 (5교시부터 출석)
       4교시«에» 등교 / 4교시부터 출석      → 1~3교시 빠짐
       조회 지각                            → 조회만 늦음
       4교시 «이후» 조퇴                    → 5교시부터 빠짐
       4교시«에» 조퇴                       → 4교시부터 빠짐
       날짜 안 적음 = 오늘 · «어제» «11/17» «17일» · 결석 기간 «11/17~11/19» (주말은 건너뜀)
       분류(질병·미인정·출석인정)가 없거나, 교시가 없거나, 동명이인이면 넣지 않고 되묻는다. «결과» 는 아직 안 된다.

  이렇게 보이면 성공: 날짜·번호·분류·빠진 교시가 선생님 뜻과 같다.


[ X-4. 출결 넣기 시험 — 저장 안 함 (담임만) ]

  ① 선생님께 여쭤본다: «○번 학생 줄에 화면에만 넣어 보고 저장하지 않고 버리는 시험을 해도 될까요?» — 좋다고 하실 때만.
  ② .\.venv\Scripts\python.exe -X utf8 attendance_quick.py 넣기 "받은 문장" --저장안함
     → «넣은 뒤(저장 전) N번 줄: …» 과 «다시 조회 → N번 줄이 넣기 전으로 돌아옴 ✅» 가 나와야 한다.
  - «이 날은 3교시까지입니다 … 없는 교시» → 정상인 안전장치다. 그날 있는 교시로 문장을 바꿔 다시.
  - «출결마감구분 … Timeout» → 생기부 마감·일마감 등으로 칸이 잠긴 것일 수 있다. 선생님께 여쭤보고, 잠겨 있으면 풀린 뒤 다시.
  - «돌아옴 ⚠️» 이 나오면 멈추고 선생님께 나이스 화면을 봐 달라고 한다.

  이렇게 보이면 성공: «돌아옴 ✅». 실제 저장은 선생님이 위젯에서 처음 쓰실 때 하고, 그때 나이스 목록을 같이 본다.


[ X-5. 출결마감 상태 보기 시험 (담임만) ]

  ① .\.venv\Scripts\python.exe -X utf8 month_close.py <지난달 YYYY-MM>      (--close 는 붙이지 않는다)
  ② 마지막 줄 RESULT_JSON 에서 일마감 상태와 월마감 «마감됨 / 마감 안 됨» 만 읽어 드린다.
  ③ 선생님께: «[출결마감] → 달 고르기 → [마감하기] 를 누르면 일마감(한 번에)과 월마감을 이어서 합니다.
     그 달 마지막 평일 전에는 안 됩니다. 마감한 날은 출결을 더 못 넣습니다(나이스에서 마감취소).»

  이렇게 보이면 성공: «상태만 보기» 로 돌았고 아무것도 누르지 않았다.


[ X-6. 학교회계 — 기안자 이름 정하기 · 시험 ]

  ① 선생님께 여쭤본다: «품의 개요 맨 끝 "5. 품의요청자: ___" 에 들어갈 이름을 어떻게 적을까요?
     (예: 교사 홍길동 / 3학년부 교사 홍길동)» — 선생님 이름은 인증서 이름과 같을 때가 많으니 «교사 (인증서 이름)» 으로 할지 먼저 여쭤봐도 된다.
  ② 받은 글자를 설정에 넣는다 (코드·저장소에는 넣지 않는다). «받은 글자» 자리만 바꿔서:
       .\.venv\Scripts\python.exe -X utf8 -c "import teacher_config as t; c=t.load_config(); c['punui_requester']='받은 글자'; t.save_config(c); print('기안자 저장됨')"
     제목·개요 틀을 학교 양식대로 바꾸고 싶다고 하시면 punui_title / punui_body 에 넣는다 ({년도} = 회계연도, {기안자} = 위 이름).
     기본 개요 틀:
       {년도}학년도  물품을 구매하고자 합니다.
         1. 내용:
         2. 내역:
         3. 금액: 금원(금원)
         4. 구매처(예정):
         5. 품의요청자: {기안자}.  끝.
  ③ 선생님께 «평소 크롬에 에듀파인이 켜져 있으면 로그아웃해 주세요(중복 로그인)» 라고 한 뒤:
       .\.venv\Scripts\python.exe -X utf8 widget\바로가기_엔진.py edufine punui
     → STEP «학교회계로 바꾸는 중» → «품의등록 여는 중» → «제목·개요 채우는 중» → READY.
  ④ 선생님께 에듀파인 창을 보시라고 한다: 업무가 «학교회계», 제목 «2026 물품을 구입하고자 합니다.», 개요 끝에 기안자 이름,
     «품의번호» 칸이 비어 있으면(= 저장 안 됨) 성공. 그 화면은 저장하지 않았으니 그냥 두셔도 된다.
  - «업무 선택칸을 못 찾았어요» → 화면이 늦게 뜬 것. 한 번 더.
  - «왼쪽 메뉴에 "품의/정산" 이 없어요» → 그 선생님 계정에 학교회계 품의 권한이 없을 수 있다. 행정실에 여쭤보시라고 한다.

  이렇게 보이면 성공: READY 가 나오고, 품의등록 화면에 제목·개요만 채워져 있다.


[ X-7. 위젯 다시 켜기 · 단추 확인 ]

  ① 떠 있는 위젯을 끈다: Stop-Process -Name pythonw -Confirm:$false
  ② 다시 띄운다 — ★ 위젯 파일 위치를 «전부» 적어야 한다 (짧게 적으면 아무 말 없이 안 뜬다). 폴더 위치는 Get-Location 으로 보고 바꿔 넣는다:
       Start-Process -FilePath ".\.venv\Scripts\pythonw.exe" -ArgumentList '"<이 폴더>\widget\바로가기위젯.pyw"' -WorkingDirectory "<이 폴더>\widget"
  ③ 선생님께: «위젯 단추가 [나이스] [출결] [출결마감] [에듀파인] [학교회계] [문서등록대장] [공람] [검수] [복무] 순서로 보이나요?»
  ④ 쓰는 법을 알려 드린다:
     - [출결] 한 줄에 한 학생 → [풀어 보기] → 맞으면 [나이스에 넣기]. 틀렸으면 [고치기] — 적은 문장은 다 저장될 때까지 지워지지 않는다.
     - 반 명단이 바뀌면(전입·전출) 위젯 오른쪽 클릭 → «반 명단 다시 읽기 (출결용)».
     - [출결마감] 은 그 달 출결을 다 넣은 뒤에.
     - [학교회계] 는 화면을 채우기만 한다. 예산·품목·결재선을 넣고 [저장] 은 선생님이 직접.
  ⑤ 처음 실제로 [나이스에 넣기] 를 하실 때는 한 건만 넣고, 나이스 일일출결관리에서 그 줄을 눈으로 확인하시라고 한다.

  이렇게 보이면 성공: 단추 아홉 개가 위 순서로 떠 있다.
