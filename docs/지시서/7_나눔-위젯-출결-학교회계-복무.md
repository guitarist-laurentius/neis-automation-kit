코드는 이미 깃허브에 올라가 있으니 새로 짜지 말고, 받아서 설정하고 시험만 해.

[말하는 방식]
- 모든 대화는 한국어로, 존댓말로, 짧게. 한 번에 한 단계씩 하고 끝나면 «다음 갈까요?» 하고 멈춰.
- 단계를 말할 때는 X-0, X-1 … 번호로 말해.
- 전문용어(경로, 환경변수, 가상환경, 터미널, 포트, 브랜치) 쓰지 마. 명령은 전부 네가 직접 실행해.
  선생님께는 [허용] 누르기 · 질문에 답하기 · 화면 보고 알려 주기만 부탁해.
- 명령은 «.\.venv\Scripts\python.exe -X utf8 …» 모양으로 한 줄씩. & 로 시작하지 말고 $env: 도 쓰지 마.
- 매 단계 끝에 «이렇게 보이면 성공입니다: …» 를 한 줄 넣어.
- 에러가 나면 «잘못하신 게 아닙니다» 를 먼저 말하고, 에러 글자를 그대로 보여 준 뒤 고쳐.

[하지 말 것]
- 학생 이름을 대화에 늘어놓지 마. 명단은 «몇 명» 으로만 말해. 명령 결과에 이름이 섞여 나오면 가려서 전해.
- 인증서 암호·리로스쿨 비밀번호·연락처를 대화로 받거나 찍지 마. 비밀번호는 따로 띄운 검은 창에만 치게 해.
  선생님이 대화창에 비밀번호를 치려고 하면 말리고 검은 창으로 안내해. 설정 확인은 .\.venv\Scripts\python.exe -X utf8 show_config.py 로.
- 시험할 때 나이스 출결을 «저장» 하지 마. 출결 시험은 반드시 --저장안함 (화면에 넣고 다시 조회해 버린다).
- month_close.py 에 --close 를 붙여 돌리지 마 ([마감하기] 는 선생님이 위젯에서 직접). 시험은 «상태 보기» 만.
- 복무 시험은 --dry-run 으로만 (승인요청 안 누름). 에듀파인 품의에서 [저장]·[결재요청]·[삭제] 를 누르지 마.
- 위젯 코드를 새로 짜거나 고치지 마. 막히면 고치기 전에 선생님께 먼저 말씀드려.
- 파일 지우기, 이미 있는 설정 파일 통째로 덮어쓰기, 시키지 않은 커밋·푸시 하지 마.
- 학교 이름·리로스쿨 주소·아이디를 저장소 파일에 적지 마 (설정 파일에만 들어간다).

[ X-4. 출결 문장 풀이 시험 — 나이스 안 열림 (담임만) ]

  ① 선생님께 시험용 문장을 하나 받는다. 예) «오늘, ○○○, 4교시 이후, 질병지각, 사유: 병원 진료»
  ② .\.venv\Scripts\python.exe -X utf8 attendance_quick.py 풀이 "받은 문장"
     → «📝 11/24(화) · 7번 ○○○ · 질병지각 · 1~4교시 빠짐 (5교시부터 출석) · 사유: 병원 진료» 처럼 나온다. 이름은 가려서 전해.
  ③ 적는 법을 표로 알려 드린다:
       형식      날짜, 이름, 교시, 분류+종류, 사유: 내용   (쉼표·순서는 자유. 한 줄에 한 학생)
       지각      4교시 «이후» 등교 / 4교시 끝나고 옴 → 1~4교시 빠짐 · 4교시«에»(«부터») 등교 → 1~3교시 빠짐 · 조회 지각 → 조회만
       조퇴      4교시 «이후» 조퇴 → 5교시부터 빠짐 · 4교시«에»(«부터») 조퇴 → 4교시부터 빠짐
       결과      «5,6교시 인정결과» «3~5교시 질병결과» → 그 교시만 빠짐
       사유      «사유:» 뒤 줄 끝까지 → 나이스 출결마감구분 «사유» 칸에 들어간다. 안 적으면 비워 둔다
       날짜      안 적으면 오늘 · «어제» «11/17» «11.17» «17일» · 기간 «11/16~11/18» «11.16~18» «16~18일» (주말은 건너뜀)
                 결석이 아니어도 기간이면 그 날마다 같은 교시로 넣는다
       되묻는 것 분류(질병·미인정·출석인정)·교시가 없을 때, 동명이인, 날짜로 못 읽은 숫자, 고른 날이 모두 주말, 그날 없는 교시

  이렇게 보이면 성공: 날짜·번호·분류·빠진 교시·사유가 선생님 뜻과 같다.

  ③ «평소 크롬에 에듀파인이 켜져 있으면 로그아웃해 주세요(중복 로그인)» 라고 한 뒤:
       .\.venv\Scripts\python.exe -X utf8 widget\바로가기_엔진.py edufine punui
     → «학교회계로 바꾸는 중» → «품의등록 여는 중» → «제목·개요 채우는 중» → READY.
  ④ 선생님께 에듀파인 창을 보시라고 한다: 업무 «학교회계», 제목·개요가 채워졌고, «품의번호» 칸이 비어 있으면(= 저장 안 됨) 성공.
  - «업무 선택칸 …» 실패 → 화면이 늦게 뜬 것. 한 번 더.
  - «왼쪽 메뉴에 "품의/정산" 이 없어요» → 그 계정에 학교회계 품의 권한이 없을 수 있다. 행정실에 여쭤보시라고 한다.

  이렇게 보이면 성공: READY 가 나오고, 품의등록 화면에 제목·개요만 채워져 있다.


[ X-8. 복무 41조연수 · 초과근무 (쓰실 때만) ]

  ① 여쭤본다 (지어내지 마 — 학교 공지 그대로):
     - 41조 연수의 사유 문구와 목적지 (예: «수업연구 및 자율연수», «자택»)
     - 41조 연수용 개인결재선 이름 · 초과근무용 개인결재선 이름 (나이스 «개인결재선» 에 저장해 둔 이름)
  ② 설정에 넣는다 (받은 글자로 바꿔서):
       .\.venv\Scripts\python.exe -X utf8 -c "import teacher_config as t; c=t.load_config(); c.update({'training_reason':'사유','training_destination':'목적지','training_approval_line':'41조 결재선','overtime_approval_line':'초과근무 결재선'}); t.save_config(c); print('복무 설정 4개 저장됨')"
  ③ 폼만 채우는 시험 (승인요청 안 누름):
       .\.venv\Scripts\python.exe -X utf8 main_bokmu.py --type 41조연수 --date <다음 방학 평일> --end-date <그 주 금요일> --destination "시험용" --reason "시험용" --approval-line "시험용" --dry-run
       → «근무상황소분류 = 교육공무원법제41조연수» 와 «폼 입력 완료»
       .\.venv\Scripts\python.exe -X utf8 main_overtime.py --date <다음 평일> --start 16:30 --end 18:30 --task "시험용" --dry-run
       → «나이스에 들어간 값 …» (인정시간 합은 나이스가 계산한 값 그대로 보고)
     날짜·요일은 직접 계산하지 말고 코드로 확인한다.

  이렇게 보이면 성공: 둘 다 «--dry-run 모드: 승인요청을 누르지 않고 종료».


[ X-9. 리로스쿨 자동 로그인 (쓰실 때만) ]

  ① «리로스쿨 주소·아이디·비밀번호는 지금 뜨는 검은 창에만 넣어 주세요. 이 대화창에는 적지 마세요» 라고 한 뒤 검은 창을 띄우고
     끝날 때까지 기다린다 (시간 제한 10분):
       Start-Process -FilePath ".\.venv\Scripts\python.exe" -ArgumentList "-X","utf8","widget\리로스쿨_설정.py" -Wait
     주소는 평소 로그인하는 주소 그대로 (예: https://○○○.riroschool.kr). 비밀번호는 두 번 치고, 칠 때 글자가 안 보이는 게 정상.
  ② 들어갔는지 «있음/없음» 으로만 본다 (값은 찍지 마):
       .\.venv\Scripts\python.exe -X utf8 -c "import json,keyring,teacher_config as T;c=json.loads(T.CONFIG_FILE.read_text(encoding='utf-8'));i=c.get('riro_id','');print('주소',bool(c.get('riro_url')),'아이디',bool(i),'비밀번호',bool(i and keyring.get_password(T.KEYRING_SERVICE,'riroschool:'+i)))"
  ③ 로그인 시험:
       .\.venv\Scripts\python.exe -X utf8 widget\바로가기_엔진.py riro open
     → «리로스쿨 여는 중» → «로그인 화면 여는 중» → «로그인 중» → READY. 선생님께 크롬 창에 로그인된 화면이 보이는지 여쭤봐.
  - «로그인이 안 됐어요» → 비밀번호를 Caps Lock 켠 채 넣었을 수 있다. ① 을 다시.
  - 같은 리로스쿨을 다른 크롬에서 동시에 열면 첫 열기가 끊길 수 있다(ERR_ABORTED). 한 번 더.

  이렇게 보이면 성공: READY 가 나오고 리로스쿨이 로그인된 채 앞에 떠 있다.


[ X-10. 위젯 다시 켜기 · 얼굴 고르기 · 도넛 확인 ]

  ① 떠 있는 위젯을 끈다: Stop-Process -Name pythonw -Confirm:$false
  ② 다시 띄운다 — ★ 위젯 파일 위치를 «전부» 적어야 한다 (짧게 적으면 아무 말 없이 안 뜬다). Get-Location 으로 이 폴더 위치를 보고 <이 폴더> 를 바꿔 넣는다:
       Start-Process -FilePath ".\.venv\Scripts\pythonw.exe" -ArgumentList '"<이 폴더>\widget\바로가기위젯.pyw"' -WorkingDirectory "<이 폴더>\widget"
  ③ 처음이면 «위젯 얼굴을 골라 주세요» 창이 뜬다. 선생님이 마음에 드는 얼굴을 누르시게 한다
     (궁예·곰돌이·고양이·병아리·스마일·안경 선생님, 또는 «내 그림 파일…» 로 사진·그림). 그냥 닫으면 스마일.
  ④ 여쭤본다: «얼굴에 마우스를 올리면 도넛 9칸이 [나이스]부터 시계 방향으로 [출결] [출결마감] [에듀파인] [물품구입] [문서등록대장] [공람] [리로스쿨] [복무] 순서로 펼쳐지나요?»
  ⑤ 쓰는 법을 알려 드린다:
     - 얼굴에 마우스 → 도넛이 펼쳐진다 → 칸을 누른다. 마우스를 치우면 접힌다. 얼굴을 잡고 끌면 옮겨진다(펼친 채로도).
     - 하는 중인 일은 얼굴 머리 위 말풍선에 나온다. 궁예 얼굴이면 쉬는 동안 궁예 대사가 15초마다 바뀐다.
     - 얼굴 오른쪽 클릭 메뉴: «얼굴 바꾸기» · «궁예 한마디» 끄고 켜기 · «리로스쿨 설정» · «물품 검수» · «반 명단 다시 읽기 (출결용)» · «위젯 끄기».
     - [출결] 한 줄에 한 학생 → [풀어 보기] → 맞으면 [나이스에 넣기]. 틀렸으면 [고치기] — 적은 문장은 다 저장될 때까지 남는다.
     - [출결마감] 은 그 달 출결을 다 넣은 뒤에.
     - [물품구입] 은 화면을 채우기만 한다. 예산·품목·결재선을 넣고 [저장] 은 선생님이 직접.
     - [복무] 의 [상신] 은 나이스에 승인요청까지 실제로 올린다. 처음엔 한 건만 올리고 나이스 목록에서 확인.
     - 위젯은 다음에 컴퓨터를 켜면 저절로 뜬다.

  이렇게 보이면 성공: 얼굴이 떠 있고, 마우스를 올리면 도넛 9칸이 위 순서로 펼쳐진다.
